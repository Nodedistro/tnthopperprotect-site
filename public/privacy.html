What TNT Hopper Protect processes when you browse, report an issue, log in as an admin, or receive an announcement.

Effective date: October 3, 2026

1. Scope

This policy describes information handled by the TNT Hopper Protect website and release-announcement application operated under the name NodeDistro MC Plugins. It does not replace the privacy policies of Discord, Modrinth, server owners, or other services you use.

2. Information processed

  • Issue reports: title, category, description, Minecraft version, server software, optional contact information, and generated report ID, status, and submission time.
  • Admin access: administrators provide a secret for authentication. The backend uses a session cookie to maintain access; ordinary visitors do not need an admin login.
  • Release announcements: public release titles, versions, supported Minecraft versions and loaders, changelogs, and download links.
  • Technical data: hosting and API providers may process IP addresses, request times, browser or device information, and error logs when serving and protecting the service.

3. How information is used

Information is used to display and respond to reports, diagnose compatibility problems, publish release news, authenticate administrators, maintain reliability, and address abuse. The website does not include advertising trackers or analytics scripts.

4. Public information and service providers

Report text, categories, software versions, status, and timestamps may appear on the public issue tracker. The optional contact field is excluded from the public issue-list response. Public release information may be displayed on the website and sent to the configured Discord channel.

The service uses AWS for hosting and API execution and Supabase for database storage. GitHub hosts the project and may run release automation; Modrinth provides public release information and downloads; Discord delivers announcements. These providers process information under their own policies. We may disclose information if required by law or necessary to address abuse or protect rights.

5. Cookies and security

The administrator session cookie supports authenticated publishing and is separate from ordinary public browsing. You can clear cookies in your browser to end that session. Credentials are intended to remain on backend systems, not public frontend files. No online service can guarantee absolute security.

6. Retention

Issue records and release posts remain stored until removed; the application does not automatically expire them. We review removal requests and retain information only as needed for support, project history, security, or applicable obligations. Copies may remain temporarily in backups or provider logs.

7. Your choices and requests

You may omit optional contact information and avoid placing personal information in public report text. To request access, correction, or deletion of information you submitted, email support@nodedistro.com with the report or information concerned. Do not send passwords, bot tokens, or identity documents with your initial request.

8. Children

Do not submit personal information if you are below the age at which you may lawfully do so without a parent or guardian’s permission. Discord’s own age requirements apply when using Discord.

9. Changes

We will revise this policy when the service’s data practices change and update the date above. Material changes will be communicated through the website or another appropriate channel.
