Core behavior

The same rule on every platform.

All four builds are focused on the exact same gameplay behavior.

🛒

Protect hopper minecarts

Explosion damage that would destroy a hopper minecart is cancelled.

💥

Keep TNT behavior

TNT still detonates and regular blocks can still be destroyed normally.

⚡

Lightweight

No unrelated mechanics. The mod/plugin only changes hopper-minecart explosion damage.
