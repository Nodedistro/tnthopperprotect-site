Install the right build

  1. Download the matching Minecraft version and loader JAR from Modrinth releases.
  2. Stop your server or game before changing installed JARs.
  3. For Paper, put its JAR in plugins/. For Fabric, Forge, or NeoForge, put the matching JAR in mods/.
  4. Remove the older copy of this plugin or mod, then restart.
  5. Check your startup log for successful loading before testing your build.
Version 2.0.0 builds currently target Minecraft 26.1.2 and Java 25+. Minecraft 26.2 builds are not yet verified. Check each release’s compatibility.

Paper configuration

The Paper plugin creates its configuration after the first start. An empty world list enables protection in every world.

protect-hopper-minecarts: true
enabled-worlds: []

Add world names to enabled-worlds to limit protection. Restart after editing. This configuration applies to Paper.

What stays protected?

Hopper minecarts are protected from explosion damage. TNT still detonates and destroys normal blocks. Other entities and damage sources are outside this protection.

Check the basics

The mod does not load

Confirm the Minecraft version, Java version, and loader match the JAR. Check for duplicate copies and read the startup log for dependency errors.

Hopper minecarts still break

Check that the plugin loaded and, on Paper, that protection is enabled for this world. Include your loader and server versions in your report.

TNT no longer breaks blocks

This project does not cancel normal block explosions. Check other mods, plugins, and server settings.
