When something goes sideways.

The mod or plugin does not load

Check Minecraft, Java, and loader versions. Remove duplicate copies and read the startup log.

Hopper minecarts still break

Confirm the correct build loaded. On Paper, check protection is enabled for that world.

TNT stopped breaking blocks

This project does not cancel normal block explosions. Check other mods, plugins, or server settings.
