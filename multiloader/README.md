# TNT Hopper Protect — Multi-loader

Minecraft Java 26.1.2 builds for Paper, Fabric, NeoForge, and Forge.

Each platform has its own JAR. Paper goes in `plugins/`; Fabric/NeoForge/Forge go in `mods/`.

The core behavior is the same everywhere: TNT and other explosion block damage remains enabled, while hopper minecarts are protected from explosion damage.

GitHub Actions builds all four targets automatically and uploads the JARs as workflow artifacts.
